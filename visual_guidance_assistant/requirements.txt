# ---------------------------------------------------------------------------
# INSTALL: `pip install -r requirements.txt` ALONE IS NOT ENOUGH on Windows.
# Run these three commands, in this order, from the project root:
#
#   python -m pip install -r requirements.txt
#   python -m pip install --no-deps face_recognition
#   python -m pip install Click Pillow
#
# Why face_recognition needs --no-deps:
#   face_recognition declares a plain `dlib>=19.7` dependency. Building real
#   dlib on Windows needs CMake + Visual C++ Build Tools; without them pip fails
#   AND rolls back every other package in the same command (that is how a torch
#   + opencv install silently ends up with nothing installed).
#   dlib-bin below is the prebuilt wheel and provides the importable `dlib`
#   module, which is what matters at runtime — but pip's resolver does not treat
#   it as satisfying the `dlib` requirement, so the dependency has to be
#   bypassed with --no-deps. Click and Pillow are face_recognition's remaining
#   real dependencies and are installed explicitly in step 3.
# ---------------------------------------------------------------------------

# Prebuilt dlib wheel — no compiler required. Must be installed before
